# Architecture decisions (ADR log)

| #    | Decision                                                                                                                         | Why                                                                                                                    | Status                       |
| ---- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| 0001 | **pnpm + Turborepo monorepo**, packages ship TS sources (no package build)                                                       | One version of each contract; Next transpiles, tsup bundles for Node services; fast feedback                           | Accepted                     |
| 0002 | **TypeScript 6.0**, not 7.0                                                                                                      | TS 7 (native compiler) is days old; Next.js / tooling integration not yet proven                                       | Accepted, revisit in Phase 7 |
| 0003 | **Better Auth** for identity (email+password, sessions, reset), our own tables for teams/roles                                   | Mature, Prisma adapter, self-hosted; teams/RBAC stay in our domain layer where rules live                              | Accepted                     |
| 0004 | **Prisma 7** with `@prisma/adapter-pg`, config in `prisma.config.ts`, single root `.env`                                         | Current stable major; Prisma 8 is RC                                                                                   | Accepted                     |
| 0005 | **UUIDv7** ids, `timestamptz(3)`                                                                                                 | Time-ordered (index locality), generated offline by Bridges for idempotent events                                      | Accepted                     |
| 0006 | **Composite tenant foreign keys** `(projectId, teamId) → projects(id, teamId)`                                                   | The database itself refuses cross-team references, in addition to service checks                                       | Accepted                     |
| 0007 | **Transactional outbox** (`events` table with sequence) for realtime                                                             | No lost or phantom events; replay after reconnect by sequence                                                          | Accepted                     |
| 0008 | Request / Task / Deliverable are **three entities** + immutable `request_history`                                                | Spec requirement; each has its own lifecycle and permissions                                                           | Accepted                     |
| 0009 | Knowledge search: PostgreSQL FTS + `pg_trgm` first, **pgvector** embeddings in Phase 5                                           | No new infrastructure; extensions enabled in the init migration                                                        | Accepted                     |
| 0010 | **MinIO built from source** locally (`infrastructure/docker/minio`)                                                              | Upstream stopped publishing public images; any S3 provider works in prod                                               | Accepted                     |
| 0011 | Constraints Prisma can't express (partial unique, CHECK) live in **raw SQL in migrations**                                       | Integrity enforced by PostgreSQL, documented in `docs/database/schema.md`                                              | Accepted                     |
| 0012 | Agents expose only **declared state and technical events**                                                                       | Hooks see tool calls, not reasoning; we never store raw conversations                                                  | Accepted                     |
| 0013 | UI mutations use **Server Actions**, external clients use **REST**; both call the same services                                  | One code path for rules; typed actions for the UI, versioned contract for Bridge/MCP/integrations                      | Accepted                     |
| 0014 | Resources of another tenant answer **404, never 403**                                                                            | Existence of other teams' data never leaks                                                                             | Accepted                     |
| 0015 | Input validation runs **before** authorization (422 before 403/404)                                                              | Zod parse is cheap and reveals nothing about stored data                                                               | Accepted                     |
| 0016 | **Local embeddings** (transformers.js, multilingual-e5-small, 384 dims) in a dedicated worker role, never in the Next.js process | Private by default (no content to a third party), FR/EN, no API key; heavy native runtime isolated; full-text fallback | Accepted                     |
| 0017 | Knowledge is **private or project-visible by explicit choice**; reads are tracked to warn on changes                             | Developers decide what leaves their session; consumers of a contract learn when it changes                             | Accepted                     |
