# Realtime protocol (v1.0)

Contracts live in code: `@devsync/protocol` (envelope, ack, handshake, rooms) and
`@devsync/event-schemas` (payload per event type). This page documents them.

## Connection

Socket.IO over WSS to `REALTIME_URL`. Handshake (`auth`):

```json
{
  "token": "<realtime JWT (dashboard) or device token (bridge)>",
  "clientKind": "bridge",
  "protocolVersion": "1.0",
  "clientVersion": "0.3.1",
  "lastSequence": { "0190f3a2-7b1c-7d2e-8f00-0123456789ac": 1842 }
}
```

Refusals arrive as `connect_error` with message `BAD_REQUEST` (shape / incompatible major version),
`UNAUTHENTICATED` (bad, expired or revoked token) or `INTERNAL`. Identity comes from the token only.

Rooms are joined by the server after authorization: `team:<id>`, `project:<id>`, `user:<id>`, `agent:<id>`.

## Channels

| Channel | Direction | Ack |
| --- | --- | --- |
| `event:publish` | client → server | `Ack` |
| `event:deliver` | server → client | client acks `{ ok: true, id }` |
| `session:resume` | client → server `{ lastSequence }` | server replays missed `event:deliver` in order |
| `session:error` | server → client | – |

## Envelope

```json
{
  "id": "0193a1b2-5c3d-7e4f-8a00-1b2c3d4e5f60",
  "type": "collaboration.request.created",
  "version": "1.0",
  "timestamp": "2026-11-18T10:42:07.120Z",
  "teamId": "0190f3a2-7b1c-7d2e-8f00-0123456789ac",
  "projectId": "0190f3a2-7b1c-7d2e-8f00-0123456789ff",
  "actor": { "type": "AGENT", "userId": "0190…01", "agentId": "0190…a1" },
  "sequence": 1843,
  "correlationId": "0193a1b2-5c3d-7e4f-8a00-1b2c3d4e5f00",
  "payload": { }
}
```

- `id` is generated by the producer (UUIDv7) and is the **idempotency key**: a consumer ignores an id it has seen.
- `sequence` is assigned when the event is persisted to the `events` outbox; monotonic.
- `version` major mismatch ⇒ refused.

## Ack

```json
{ "ok": true,  "id": "0193…5f60", "sequence": 1843, "duplicate": false }
{ "ok": false, "id": "0193…5f60", "code": "INVALID_PAYLOAD", "message": "…", "retryable": false }
```

Producers retry with exponential backoff (1s → 60s, jitter) until an ack arrives, then drop the
message from their local queue. `duplicate: true` means the server already had that id: success.

## Event catalog

| Type | Payload (abridged) |
| --- | --- |
| `agent.connected` | `agentId, userId, sessionId?, machineId, pluginVersion?` |
| `agent.disconnected` | `agentId, userId, sessionId?, reason: client\|timeout\|revoked\|server` |
| `agent.status.updated` | `agentId, userId, status, previousStatus?` |
| `agent.activity.updated` | `agentId, userId, kind, summary (≤500), tool?` |
| `collaboration.request.created` / `.accepted` | `requestId, title, type, status, priority, requesterUserId, assigneeUserId?, assigneeAgentId?` |
| `collaboration.request.updated` | same + `changes: string[]` |
| `collaboration.request.rejected` | same + `reason?` |
| `collaboration.deliverable.ready` | `requestId, deliverableId, versionId, version, title, format` |
| `knowledge.published` | `knowledgeId, versionId, version, title, tags[]` |
| `git.activity.detected` | `repositoryId, agentId?, branch, head, modifiedFiles[]` |
| `git.conflict.detected` | `conflictId, repositoryId, kind, filePath, agentIds[]` |
| `notification.created` | `notificationId, userId, kind, title, body?, link?, playSound` |

## Bridge local IPC (Phase 2)

Newline-delimited JSON over a Unix socket (`~/.devsync/bridge.sock`, mode 0600) / named pipe on
Windows. Requests `{ id, method, params }`, responses `{ id, result | error }`. Methods:
`session.register`, `session.heartbeat`, `session.end`, `event.publish`, `inbox.list`, `api.call`.
